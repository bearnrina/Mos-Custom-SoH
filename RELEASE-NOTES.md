# Mo's Custom SoH v1.1

An independent custom Windows build of Ship of Harkinian, based on upstream 9.2.3. Mo's release version is separate from the upstream engine version.

## Highlights

- Local Item Shuffle is now a selectable game mode with Start, Generate New Seed, and Review Seed menus styled to match the existing quest screens.
- Seed review uses four ratings: Standard, Tricky, Glitches Required, and Unverified. No returns to the shuffle menu so you can regenerate. Unverified seeds may be unbeatable or require advanced glitches.
- Upgrade families progress sequentially, including scales, strength, wallets, weapon capacities, and Hookshot/Longshot. Existing inventory is not changed retroactively.
- Chest-opening music plays during generation. Rating fanfares are Obtain Heart Container (Standard), Obtain Item (Tricky), Enter Zelda (Glitches Required), and Obtain Small Item (Unverified).
- The shuffle subtitle matches the displayed logo resolution. The old Local Dungeon Item Shuffle checkbox has been removed.
- Mo's Custom Controls combines C-Up equipping, D-pad equipment controls, and relocated Navi/first-person controls.
- Optional assets are detected: standard Navi text works without the icon mod; MM Jump Flips is disabled without its animations; Roc's Feather works without HD artwork.
- Mo's OG+, Nostalgia+, and Vanilla+ built-in presets have been updated to the author's tested settings.
- Speed modifiers include climbing, block pushing, and crawling. Gossip-stone dialogue, age-restricted chest messages, and custom menu wording have been revised.
- Breakable arrow signs are packaged as a standalone mod.

## Downloads and updating

The Windows x64 download contains the current tested Release executable, engine archive, extraction descriptions, notices, and standalone arrow-sign mod. The source download includes current customized libultraship and Torch source trees without Git history.

Close the game and back up existing saves/configuration before updating. Extract into a new writable folder first. Supply your own supported game archive or use the extractor with your own legally acquired supported ROM. Never redistribute those game files.

No ROM, extracted oot.o2r/oot-mq.o2r, save, personal configuration, temporary preset, or optional animation/icon/feather archive is included.

The author has tested the current Release build in-game. The exported source has not received a separate clean build, and the author confirmed that this packaged Windows download passed its fresh-folder test.
